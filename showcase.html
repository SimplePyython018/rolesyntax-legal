HOW IT WORKS

Six-Step Role Flow

See how RoleSyntax handles a Python level from selection to controlled level changes.

01

SELECT

Choose a level

Members choose their Python level using the RoleSyntax selector.
IMAGE: images/select.png
02

VALIDATE

Check current roles

RoleSyntax checks whether the member already has an active Python level.
IMAGE: images/validate.png
03

ASSIGN

Apply the role

A valid selection results in the corresponding Python level role being applied.
IMAGE: images/assign.png
04

PROTECT

Block conflicting changes

Direct switching is blocked when another Python level is already active.
IMAGE: images/protect.png
05

UNSELECT

Clear the current role

Members can remove the active Python level before selecting another one.
IMAGE: images/unselect.png
06

SELECT AGAIN

Choose a new level

After clearing the previous role, the member can safely choose another level.
IMAGE: images/select-again.png
